# Project Rules & Workflow Instructions

## Rule 1: Quy Trình Làm Việc Với File Learning (`learning.md`)

1. **Trước khi thực hiện công việc (Pre-task):**
   - Luôn đọc file `learning.md` ở thư mục gốc dự án trước để nắm rõ kiến trúc hệ thống, quy ước code, luồng WebSocket/Draft state machine, và các bài học rút ra từ các đợt refactor trước.

2. **Sau khi thực hiện thay đổi (Post-task):**
   - Sau khi sửa đổi, thêm tính năng hoặc refactor các thành phần quan trọng của dự án, phải cập nhật những kiến thức mới, quyết định thiết kế hoặc bài học kinh nghiệm vừa học được vào file `learning.md`.

---

## Rule 2: Quy Trình Thiết Kế Giao Diện (UI/UX Design Workflow)

- **Khi phát triển, sửa đổi hoặc nâng cấp giao diện (UI/UX):**
  - Luôn kiểm tra và tuân thủ các hướng dẫn, tiêu chuẩn thiết kế từ các Skill đã được thêm vào hệ thống (Skills trong thư mục `.agents/skills/` hoặc global config).
  - Đảm bảo tính nhất quán về màu sắc (Tailwind Theme Tokens), phông chữ, responsive layout, micro-animations và trải nghiệm người dùng cao cấp (Tactile Esport Aesthetics).
